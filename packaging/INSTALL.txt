Meowcorder install, remove and use (works fully offline)
=====================================================

Windows
  Run windows\Meowcorder-Setup.exe. It installs two things: the VST3 plugin for your DAW
  (C:\Program Files\Common Files\VST3, fixed location, all users) and the standalone app plus manual
  (C:\Program Files\Studio 87\Meowcorder, the folder the installer asks about).
  Windows may show a blue "unknown publisher" screen because the installer is not signed:
  click "More info", then "Run anyway".
  Remove: Settings > Apps > Meowcorder > Uninstall. It asks if you also want your saved presets deleted
  (default is No, so they stay).

macOS
  Open macos\Meowcorder-macOS.pkg. It installs the VST3 plugin, the standalone app, the manual and "Uninstall Meowcorder".
  The installer is not notarized: if macOS blocks it, open System Settings > Privacy & Security and choose "Open Anyway".
  Remove: open "Uninstall Meowcorder" in the Applications folder. It asks if you also want your saved presets deleted
  (default is Keep).

Linux, DAW installed as a Flatpak (for example Bitwig, Reaper or Ardour from Flathub)
  1. Your DAW should use the org.freedesktop.Platform 25.08 runtime (check with: flatpak info <DAW id>, Runtime line).
  2. Install the file from the linux folder:
       flatpak install --user linux/Meowcorder-flatpak-25.08.flatpak
  3. Restart the DAW and rescan plugins.
  Remove: flatpak uninstall --user org.freedesktop.LinuxAudio.Plugins.Meowcorder   (removes the plugin completely)

Linux, DAW installed natively
  Extract linux/Meowcorder-linux-vst3.tar.gz into ~/.vst3  (create the folder if needed), then rescan plugins.
  Remove: delete the Meowcorder.vst3 folder from ~/.vst3.

Meowcorder keeps no presets. Your sounds are saved where you choose (File, Export), nothing is stored elsewhere.

Manual: Meowcorder-manual.pdf (the interface tour, every control and recommendations; written for the first build, new features are not in it yet).
Checksums: SHA256SUMS.
